# 运行与数据约定

## 算法和评估

所有入口仅支持双人 Kuhn/Leduc。训练和评估针对信息集策略，不允许使用对手隐藏牌。精确评估返回 NashConv、NashConv/2 和两个玩家的自对弈期望收益，收益单位为游戏筹码/局。

表格 CFR/CFR+ 为确定性完整遍历。MCCFR 使用外部采样、独立随机流和稀疏信息集表，默认5个种子。Deep CFR 默认5个种子、100个外层迭代、CPU单线程；**平均策略网络每轮训练**，`--eval-every` 只改变评估和保存频率，不改变训练日程。

默认参数用于提供明确入口，不代表已找到最优超参数。`run_width_study.sh` 对宽度64/128使用相同的5个种子及训练配置，串行运行。可通过 `PYTHON` 环境变量选择解释器，或追加训练参数，例如：

```bash
bash run_width_study.sh results/quick-study --iterations 2 --seeds 7 42 --traversals 10 --advantage-steps 5 --strategy-steps 5
```

追加参数仅应用于训练规模/设备等设置。脚本拒绝覆盖由其管理的 `--hidden`、`--output`，也不接受 `--resume`；单模型续训使用训练入口。

## 指标及文件

各入口拒绝覆盖非空目录。训练时间包括求解更新，Deep CFR 还包括全部优势与平均策略训练；不包含初始化、精确评估、保存和绘图。不同算法的迭代数不表示同等工作量。

- 表格入口：指标 CSV、各算法平均策略 JSON、参考差异、元数据、曲线。
- MCCFR：每个种子的指标和策略、汇总指标、元数据、曲线；指定 `--baseline` 后，读取同游戏同OpenSpiel版本的表格结果，输出离散检查点公共预算比较。
- Deep CFR：每个种子的指标、训练日志、平均策略、最新完整检查点及元数据；可选编号模型；根目录保存汇总和曲线。

跨种子离散度使用样本标准差，不是置信区间。节点预算只计训练节点，评估成本单独记录。指标、权重和日志不进入 Git。

## 检查点

Deep CFR 检查点包含网络、Adam状态、缓冲区及计数、独立随机流、轮数、核心源码哈希和依赖版本。保存采用临时文件替换。只加载可信的本地检查点。

恢复入口要求当前每轮策略训练日程，并沿用已存配置与评估间隔；目标轮数必须增加。恢复支持完整迭代边界，不支持梯度步中途恢复。`--device` 可指定恢复设备，但跨设备不保证后续训练逐位一致。

默认拒绝依赖版本或已存核心源码哈希不匹配。底层 `DeepCFR.load(..., allow_incompatible=True)` 仅供明确的迁移调查；训练CLI不会自动绕过检查。旧日程检查点不能静默切换到当前日程。

最新完整模型位于 `seed-N/checkpoint.pt`，`--keep-checkpoints` 额外保留 `iteration-NNNNNN.pt`。表格/MCCFR导出的策略JSON用于评估，不包含完整续训状态。

## 验证

```bash
python -m unittest discover -s tests -p 'test_*.py' -v
```

测试覆盖官方实现差分、合法动作与归一化、精确评估、样本标签、蓄水池、随机流隔离、训练日程、完整恢复及版本防护。CUDA不可用时仅跳过CUDA相关测试。不以训练损失下降代替博弈策略质量验证。
